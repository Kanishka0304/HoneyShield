# Honeyshield Project File Structure

This document describes the high-level layout of the `honeyshield` project and the purpose of the main directories and files.

## Top-level

- `backend/` - Python backend (FastAPI + SQLAlchemy + correlation/alert logic and SSH honeypot).
- `frontend/` - JavaScript frontend (Vite + React + Tailwind CSS).
- `README.md` - Main project README.
- `file_structure.md` - This file.

## Backend

Path: `backend/`

- `requirements.txt` - Python dependencies for the backend.
- `.env` - Environment variables for the backend (e.g., `DATABASE_URL`).
- `.venv/` - (Optional) Python virtual environment directory.
- `scripts/` - Utility/maintenance scripts for the backend.
  - `scripts/seed_sample_data.py` - Seeds the database with sample SSH attack events and runs correlation/risk logic.
- `honeypot/` - SSH honeypot implementation and related code.
  - `honeypot/ssh_honeypot.py` - SSH honeypot server script (captures login attempts, etc.).
- `app/` - FastAPI application code and core backend logic.
  - `app/__init__.py` - Marks `app` as a Python package.
  - `app/main.py` - FastAPI entrypoint (creates the `app` instance and defines API routes).
  - `app/config.py` - Application configuration using Pydantic settings (e.g., `DATABASE_URL`, API prefix, honeypot settings).
  - `app/database.py` - Database engine/session setup (SQLAlchemy `engine`, `SessionLocal`, and `Base`).
  - `app/models.py` - SQLAlchemy ORM models (e.g., `Event` and related entities stored in the database).
  - `app/schemas.py` - Pydantic schemas for request/response models used by the API.
  - `app/correlation.py` - Correlation and risk/alert logic (e.g., `update_risk_and_alerts` for new events).

## Frontend

Path: `frontend/`

- `.env` - Environment variables for the frontend (e.g., backend API base URL).
- `package.json` - Node.js dependencies and npm scripts (e.g., `dev`, `build`).
- `package-lock.json` - Locked dependency versions.
- `postcss.config.js` - PostCSS configuration (used with Tailwind CSS).
- `tailwind.config.js` - Tailwind CSS configuration.
- `vite.config.mjs` - Vite configuration file.
- `index.html` - Base HTML file served by Vite.
- `src/` - Frontend application source code (React).
  - `src/main.jsx` - React entrypoint, mounts the React app into `index.html`.
  - `src/App.jsx` - Main application component (routes/layout and main UI logic).
  - `src/api.js` - API helper functions for talking to the backend (e.g., fetch events/alerts).
  - `src/index.css` - Global styles (Tailwind imports and custom CSS).
- `node_modules/` - Installed Node.js packages (auto-generated by `npm install`).
  - `node_modules/.package-lock.json` - Internal npm metadata file.
